## ქართულის სპეციფიკა

**ერთი მრავლობითი ფორმა.** ქართული Qt/CLDR-ში ერთფორმიანია — 13 `numerus` სტრიქონზე
Qt Linguist ერთ ველს გვაჩვენებს, ფრანგულის ორის ნაცვლად. რიცხვის შემდეგ არსებითი
მხოლობითში რჩება: `5 შეცდომა`, არა `5 შეცდომები`.

**ბრუნვები placeholder-ებზე.** დაბოლოება ფრჩხილების **გარეთ** ჯდება:

```
Imported {count} points into layer '{layer}'!
'{layer}' შრეში იმპორტირებულია {count} წერტილი!
```

`{layer}` ბაიტ-იდენტურია, `-ში` მის გარეთაა. ეს ყველაზე ხშირი ხაფანგია.

**მთავრული ასოები არ არსებობს** — ინგლისურის Title Case არ მეორდება.

**ბრძანებები ზმნური არსებითით** — `ბოძის განთავსება`, არა `განათავსე ბოძი`.
