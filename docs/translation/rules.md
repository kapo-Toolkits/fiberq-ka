# სამი წესი

FiberQ-ის `docs/TRANSLATING.md` სამ წესს „დაურღვევლად" (*inviolable*) მოიხსენიებს.
ყველა მათგანის დარღვევა **ჩუმად** ხდება — შეცდომის შეტყობინება არ არსებობს.

## წესი 1 — `<source>` არასდროს იცვლება

ინგლისური ტექსტი არის **lookup key**. გაშვებული პლაგინი ზუსტად ამ ფრაზის თარგმანს ითხოვს.

```xml
<!-- სწორი -->
<source>Place Manhole</source>
<translation>ჭის განთავსება</translation>
```

```xml
<!-- არასწორი — ეს სტრიქონი აღარასდროს ითარგმნება -->
<source>ჭის განთავსება</source>
<translation>ჭის განთავსება</translation>
```

ერთი სიმბოლოც კი — ზედმეტი ჰარიც — და ფრაზა ჩუმად ბრუნდება ინგლისურზე.

!!! tip "თუ ინგლისურში შეცდომა შენიშნე"
    ეს რეალური და სასარგებლო აღმოჩენაა — მაგრამ `.ts` ფაილში კი არ სწორდება, არამედ
    issue იხსნება.

## წესი 2 — placeholder-ები ზუსტად უნდა შენარჩუნდეს

ფიგურულ ფრჩხილებში ჩასმული მარკერები, რომლებსაც პლაგინი გაშვებისას რეალური
მნიშვნელობებით ცვლის.

**თარგმანში უნდა გამოჩნდეს ზუსტად ისე, როგორც ინგლისურში** — ფრჩხილებით, პატარა ასოებით.
**გადაადგილება შეიძლება**, გადარქმევა/თარგმნა/წაშლა — არა.


!!! danger "წაშლილი placeholder უარესია, ვიდრე უთარგმნელი სტრიქონი"

    ვერ ფორმატირდა. მაგრამ მაშინ მომხმარებელი ინგლისურ წარწერას ხედავს.
