# ხელსაწყოთა პანელი

FiberQ-ის ღილაკები ჯგუფებადაა დაყოფილი. ქვემოთ თითოეული — რას აკეთებს და როგორ ითარგმნება.

!!! note "სვეტი „ქართული""
    ეს არის თარგმანის დრაფტი. სანამ `fiberq_ka.ts` არ დაგენერირდება, ეს სტრიქონები
    ჯერ პლაგინში არ ჩანს. [თარგმანის სტატუსი](../translation/index.md)

---

## სწრაფი პანელი

ყველაზე ხშირად გამოყენებადი 12 ღილაკი. კონტექსტი: `FiberQ`.

| ღილაკი | ქართული | რას აკეთებს |
|---|---|---|
| `Place Pole` | ბოძის განთავსება | ერთი ბოძი დაწკაპუნებულ წერტილში |
| `Place Manhole` | ჭის განთავსება | ერთი ჭა |
| `Create Route` | ტრასის შექმნა | ტრასის ხაზი **მონიშნული** ბოძებიდან/ჭებიდან |
| `Aerial Cable` | საჰაერო კაბელი | საჰაერო კაბელის გაყვანა |
| `Underground Cable` | მიწისქვეშა კაბელი | მიწისქვეშა კაბელის გაყვანა |
| `Place ODF` | ODF-ის განთავსება | |
| `Place OTB` | OTB-ის განთავსება | |
| `Place TO` | TO-ს განთავსება | |
| `Optical Slack` | ოპტიკური მარაგი | ნაგულისხმევად **საბოლოო** მარაგი |
| `Undo (FiberQ)` | გაუქმება (FiberQ) | FiberQ-ის საკუთარი ისტორია |

!!! warning "ორი ღილაკი ტყუილს ამბობს (ოდნავ)"
    `Aerial Cable` და `Underground Cable` კოდში **მაგისტრალურ** ქვეტიპზეა მიბმული,
    თუმცა წარწერა ამას არ ამბობს. სრული არჩევანი კაბელის მენიუშია. ქართულ თარგმანში
    ინგლისურის დუმილი შევინარჩუნე — მაგრამ ეს [issue #43](https://github.com/vukovicvl/fiberq/issues/43)-ში
    მეინთეინერს ვკითხე.

## ტრასირება — Routing

კონტექსტი: `RoutingUI`. ჯგუფის სახელი → **ტრასირება**.

| ჩანაწერი | ქართული | რას აკეთებს |
|---|---|---|
| `Add pole` | ბოძის დამატება | იგივე ბრძანება, რაც `Place Pole` |
| `Create route` | ტრასის შექმნა | **ავტომატურად** მონიშნული წერტილებიდან |
| `Create a route manually` | ტრასის ხელით შექმნა | წვეროებს თვითონ აწკაპუნებ |
| `Merge selected routes` | მონიშნული ტრასების შერწყმა | რამდენიმე ხაზი ერთ ობიექტად |
| `Import route from file` | ტრასის იმპორტი ფაილიდან | გარე GIS/CAD ფაილიდან |
| `Add breakpoint` | გაყოფის წერტილის დამატება | ტრასის **გეომეტრიულად** ორად გაყოფა |
| `Change route type` | ტრასის ტიპის შეცვლა | მხოლოდ ატრიბუტი, გეომეტრია არ იცვლება |
| `Route correction` | ტრასის კორექცია | პოულობს ტრასებს, რომელთა ბოლოც ბოძზე/ჭაზე არ ზის |
| `Auto GPKG` | ავტო GPKG | ავტოშენახვა GeoPackage-ში |

## კაბელის გაყვანა — Cable laying

კონტექსტი: `CableLayingUI`. ორსაფეხურიანი მენიუ:

```
კაბელის გაყვანა
├── მიწისქვეშა
│   ├── მაგისტრალური
│   ├── გამანაწილებელი
│   └── აბონენტური
└── საჰაერო
    ├── მაგისტრალური
    ├── გამანაწილებელი
    └── აბონენტური
```

სამი კლასი **ორივე მშობელქვეშ ერთსა და იმავე სტრიქონს იყენებს** — ანუ ერთი თარგმანი
ორივეს ემსახურება. [დეტალურად](../network/architecture.md)

## შენობები — Objects

კონტექსტი: `ObjectsUI`. ჯგუფის სახელი → **შენობის დახაზვა**.

| ჩანაწერი | ქართული | რას აკეთებს |
|---|---|---|
| `Object in 3 points` | შენობა 3 წერტილით | მეოთხე კუთხე გამოითვლება |
| `Object in N points` | შენობა N წერტილით | ნებისმიერი რაოდენობის წვერო |
| `Object in N points (90°)` | შენობა N წერტილით (90°) | ყველა კუთხე სწორია |
| `Digitized object (from selection)` | დიგიტალიზებული შენობა (მონიშნულიდან) | სხვა შრეში უკვე მონიშნული პოლიგონიდან |

!!! danger "`Object` = შენობა"
    გამეორება ღირს: აქ `Object` **შენობას** ნიშნავს, არა GIS-ის ობიექტს.
    [რატომ](../network/index.md)

## ნახაზები — Drawings

CAD ფაილები (DWG/DXF), რომლებიც **მიბმულია** ელემენტებზე. ეს დოკუმენტებია, არა QGIS-ში
დახაზული რამ.

| ჩანაწერი | ქართული |
|---|---|
| `Drawings` | ნახაზები |
| `Add drawing…` | ნახაზის დამატება… |
| `Open drawing (by click)` | ნახაზის გახსნა (დაწკაპუნებით) |
| `Clear drawing from element` | ნახაზის მოხსნა ელემენტიდან |

!!! tip "„მოხსნა" ≠ „წაშლა""
    მიბმის მოხსნისას **არც ფაილი იშლება დისკიდან და არც ელემენტი**. მხოლოდ კავშირი წყდება.
    tooltip-ი ამას ცალკე ადასტურებს: *"Unlink confirms nothing is deleted"*.

## მონიშვნა — Selection

| ჩანაწერი | ქართული | საშიშია? |
|---|---|---|
| `Smart selection (Multiple Layers)` | ჭკვიანი მონიშვნა (რამდენიმე შრე) | არა |
| `Clear selection` | მონიშვნის მოხსნა | **არა** — მხოლოდ მონიშვნას ხსნის |
| `Delete selected` | მონიშნულის წაშლა | **დიახ** — მონაცემებს შლის |

!!! danger "ორი მეზობელი ჩანაწერი"
    მენიუში ერთმანეთის ქვეშ დგანან. `მოხსნა` და `წაშლა` ქართულში საკმარისად შორსაა,
    რომ არ აირიოს — ეს შეგნებული არჩევანი იყო.

## დანარჩენი — FiberQPlugin

ყველაზე დიდი ჯგუფი, 132 სტრიქონი. მთავარი ღილაკები:

| ღილაკი | ქართული | რას აკეთებს |
|---|---|---|
| `Validate project` | პროექტის ვალიდაცია | 14 წესი → [ვალიდაცია](validation.md) |
| `Check (health check)` | შემოწმება (მდგომარეობის შემოწმება) | **სხვა** ფუნქციაა — მონაცემთა მთლიანობა |
| `BOM report (XLSX/CSV)` | მასალების ნუსხა — BOM (XLSX/CSV) | მასალების ჩამონათვალი |
| `Recalculate lengths…` | სიგრძეების გადათვლა… | გეომეტრიიდან თავიდან ითვლის |
| `Publish to PostGIS` | PostGIS-ში გამოქვეყნება | |
| `Preview Map` | წინასწარი დათვალიერების რუკა | PostGIS-კავშირი `config.ini`-დან |
| `Create Service Area` | მომსახურების ზონის შექმნა | ბუფერი მონიშნულის გარშემო |
| `Branch info` | განშტოების ინფორმაცია | რამდენი კაბელი იყრის თავს წერტილში |
| `Relations` | ოპტიკური კავშირები | end-to-end ლოგიკური ხაზები |
| `List of latent elements` | შუალედური ელემენტების სია | [რა არის](../network/elements.md) |
| `Color catalog` | ბოჭკოს ფერთა კოდი | **არა** სიმბოლოგიის პალიტრა |
| `Cut infrastructure` | ინფრასტრუქტურის გაჭრა | გეომეტრიის გაყოფა |
| `Fiber break` | ბოჭკოს გაწყვეტა | **რეალური დაზიანება** |
| `Move elements` | ელემენტების გადატანა | დაწკაპუნება-გადატანა-დაწკაპუნება |
| `Optical schematic view` | ოპტიკური სქემის ხედი | |
| `Import points` | წერტილების იმპორტი | KML/KMZ/DWG/Shape/GPX |
| `Save all layers to GeoPackage` | ყველა შრის შენახვა GeoPackage-ში | პროექტსაც გადაამისამართებს |
