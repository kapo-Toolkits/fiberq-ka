# ინფრასტრუქტურა

ის ნაწილი, რომელიც მიწაში და ბოძებზეა — და რომელიც ყველაზე ძვირი ჯდება.

## ბოძი — Pole

**საყრდენი, რომელზეც საჰაერო კაბელი ეკიდება.**

- **ქართულად:** `ბოძი`
- **FiberQ-ში ორი სახელით:** `Place Pole` (სწრაფი პანელი) და `Add pole` (ტრასირების
  მენიუ) — **ერთი და იგივე ბრძანებაა**, მხოლოდ ინგლისური ფორმულირება განსხვავდება.
  ქართულში ორივე `ბოძი`-ს იყენებს.

ბოძზე შეიძლება პირდაპირ დამონტაჟდეს ელემენტები: `ბოძის OTB`, `ბოძის TO`.

## მალი — Span

**მონაკვეთი ორ საყრდენს შორის.**

- **ქართულად:** `მალი` — დამკვიდრებული ქართული საინჟინრო ტერმინი
- **არა** ხიდის მალი, თუმცა სიტყვა იგივეა

ეს ტერმინი მნიშვნელოვანია `mid span slack`-ის გასაგებად → [ოპტიკური მარაგი](slack.md).

## ჭა — Manhole

**მიწისქვეშა სასინჯი კამერა მილების ტრასაზე.**

აქ კაბელს წვდომა აქვს — შედუღება, მარაგის განთავსება, ახალი მილის შეერთება.

- **ქართულად:** `საკაბელო ჭა`, მოკლედ `ჭა`
- **არა `ლუქი`** — ლუქი მხოლოდ სახურავია
- **ველზე ისმის `კოლოდეცი`** (რუსიციზმი) — დოკუმენტში `საკაბელო ჭა` ჯობია
- **ფრანგულად:** `chambre de tirage`, და **არასდროს** `trou d'homme` — მეინთეინერი ამას
  ცალკე აღნიშნავს

!!! note "მრავლობითი და მხოლობითი"
    FiberQ-ს ორივე აქვს: `Placing manholes` (მილგაყვანილობის მენიუში, მრავალსაფეხურიანი
    პროცესი) → `ჭების განთავსება`, და `Placing manhole` (ერთი ჭის განთავსება) →
    `ჭის განთავსება`.

## მილი — Duct / PE pipe

**მიწაში ჩაფლული მილი, რომელშიც კაბელი გაივლება.**

ინგლისურში ორი სიტყვაა ერთი და იმავე საგნისთვის — მენიუში `pipe`, დანარჩენ პლაგინში
`duct`. მეინთეინერი პირდაპირ წერს: **ორივე ერთი სიტყვით თარგმნეთ**.

- **ქართულად:** `მილი`
- **მენიუს ჩანაწერი:** `Place PE pipe` → `PE მილის განთავსება`
- **PE** = პოლიეთილენი, Ø 40 მმ (ჩვეულებრივი გამანაწილებელი მილი)
- **ტევადობა:** 1×1-დან 3×3-მდე — რამდენი მილი ქმნის კონას

## გადასასვლელის მილი — Transition pipe

**მსხვილი დამცავი ფუტლარი (Ø 110 მმ) იქ, სადაც ტრასა კვეთს გზას, რკინიგზას ან წყალს.**

მასში წვრილი PE მილები გაივლება.

- **ქართულად:** `გადასასვლელის მილი`
- **მასალა:** PVC, PE, Oki, თუთიაგადაკრული ფოლადი
- **არა** ადაპტერი ორ სხვადასხვა დიამეტრს შორის

!!! info "საიდან მოდის სახელი"
    „Transition" აქ ძველ სერბულ ტერმინს `prelaz` თარგმნის, რაც **გადასასვლელს** ნიშნავს.
    სწორედ ამიტომ არჩეულია `გადასასვლელის მილი` და არა `დამცავი მილი` — მეორე კარგავს
    „გადაკვეთის" აზრს.

## მილგაყვანილობა — Ducting

**მთელი მილების ინფრასტრუქტურა ერთად: ჭები + მილები.**

FiberQ-ში ეს ხელსაწყოთა ჯგუფის სახელია, რომელიც სამჯერ მეორდება (ღილაკის წარწერა,
tooltip, სტატუსის ხაზი) — ამიტომ ქართული ერთსიტყვიანი უნდა იყოს.

## თხრილი — Trench

**ღია გათხრა, სადაც მილი ან კაბელი ეწყობა.**

UI-სტრიქონად ჯერ არ გვხვდება; ლექსიკონში სისრულისთვისაა.
