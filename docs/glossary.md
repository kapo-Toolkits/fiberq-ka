# ლექსიკონი

ინგლისური ტერმინი → ქართული → რას ნიშნავს FiberQ-ში.

!!! tip "ძებნა ინგლისურ ტერმინზე"
    ქართული lunr-ის ენების სიაში არ შედის, ანუ ძებნას სტემინგი არ აქვს — „ბოძი" ვერ
    იპოვის „ბოძის"-ს. **ინგლისური ტერმინით ძებნა უფრო საიმედოა**, და ისედაც ეს არის
    დარგის რეალური გასაღები.

!!! abstract "ორი ლექსიკონი, ორი დანიშნულება"
    ეს გვერდი **ქართულენოვანი სასწავლო ვერსიაა**. Repo-ში ცალკე დევს
    [`GLOSSARY-ka.md`](https://github.com/kapo-Toolkits/fiberq-ka/blob/main/GLOSSARY-ka.md) —
    ინგლისურენოვანი, FiberQ-ის `CONTRIBUTING.md`-ის ფორმატში, upstream-ში გასაგზავნად.
    შიგთავსი იგივეა, აუდიტორია სხვა.

## არ ითარგმნება

**აკრონიმები:** `ODF` `OTB` `TO` `TB` `PE` `CRS` `BOM` `GPON` `FTTH`

**ფორმატები:** `DWG` `DXF` `GPKG` `GeoPackage` `KML` `KMZ` `GPX` `SHP` `XLSX` `CSV` `JSON` `PostGIS`

**ბაზის ველები:** `fiberq_uuid` `duzina_m` `duzina_km` `slack_m` `total_len_m` `duzina`

**შრეების სახელები:** `'Poles'` `'Route'` (ბრჭყალებში ლიტერალურია)
