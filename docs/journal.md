## 2026-09-09 — `Object` = შენობა

ყველაზე მნიშვნელოვანი ტერმინოლოგიური აღმოჩენა. FiberQ-ის `Object` სერბული `objekat`-ის
კვალია და **შენობას** ნიშნავს — ადასტურებს შრე, რომელშიც იწერება (სართულები, სარდაფი,
ქუჩა, სახლის ნომერი).

ამავე დროს QGIS-ის ქართული `feature`-ს თარგმნის როგორც **ობიექტს**.

→ `Feature → ობიექტი`, `Object → შენობა`. კონტრინტუიციურია, მაგრამ სწორი.
